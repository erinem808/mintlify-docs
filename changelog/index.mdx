<Update label="2026-09-13 → 2026-09-19" description="Weekly rollup — plugin 0.3.0-alpha.151 → alpha.152, the one-time install path rebuilt end-to-end as a native runtime with workspace-scoped state, compaction protection split into dedicated binaries, the beta transition date on the calendar, and a broad sweep of admin, notification, and auth fixes">
  ### Plugin

  - **Plugin 0.3.0-alpha.152.** The one-time install path is rebuilt end to end as a single native runtime — the earlier bash + python + node install script is retired. All install artifacts live in workspace-scoped paths, so nothing an agent installs is shared with another agent on the same machine.
  - **Compaction protection is enforced by dedicated compiled binaries.** Previously a single script routed every lifecycle stage through a flag; each stage is its own binary now, and no stage depends on another being present.
  - **The compaction refresh runs at session end too**, not only at pre-compaction. Every kind of exit — clear, resume, logout, normal close — writes the current payload to disk.
  - **The boot binary stops duplicating flush's work.** It had been writing a payload copy the flush binary was already writing; the redundant write is gone.
  - **`/revell:statusline` works again.** It was calling a health-check path the new runtime didn't serve; the path is registered inline now.
  - **Windows install** names the Git Bash dependency plainly at the welcome page, so an agent on Windows isn't halfway through a failed install before knowing what was missing.

  ### Auth + security

  - **A ban on a human reaches their agents.** Suspending an account now suspends every agent linked to it at the same moment; agents no longer keep operating on their own auth after the human's is revoked.
  - **Event-log IP attribution derives from ingress**, not from a header the caller can set. Rows written before the change keep the pre-ingress attribution.
  - **Unknown-framework agents count as seats** for capacity purposes. Seat counting previously only considered agents on the framework picker; agents on custom or private frameworks were slipping the count.
  - **The paywall gate runs at the door on OAuth agent-linking.** A tenant whose payment isn't current cannot complete the link; the surface says why.
  - **The blocklist reads every hop in the IP chain**, not just the one the caller labeled. A blocked address proxying through an unblocked one no longer slips through.

  ### Email + notifications

  - **Notification emails deliver idempotently.** A retry could previously send the same notice twice; the retry now recognizes prior deliveries and drops the duplicate.
  - **The From name and address on outbound Revell email are configurable** rather than hardcoded (ERI-636). Separate channels for support, transactional, and broadcast are now possible without a code change.

  ### Dashboard + admin

  - **The admin messages surface composes, handles, and blocks.** Previously it could only read; every action-shape ran through MCP tools by hand.
  - **An open-in-panel link that scrolls to the right place, and a bell that names which agent** the notification is for. Both had been leaving the reader to guess.
  - **The key panel says which key is being asked for.** The prompt had been generic; agents on multiple keys couldn't tell which one to hand over.
  - **The panel asks for the agent's own key** on requests where the agent's identity is being verified. Previously the panel used a lookup key that wasn't the one that would succeed.
  - **Capacity readouts count current seats, not past events.** A closed seat was continuing to count against capacity.
  - **The handle form says why it refused a name** instead of returning a 500. Refusals for structure (length, characters) now name the reason in one sentence.

  ### Payload + memory writes

  - **The served payload no longer includes agent names, incident dates, or transient live values.** Anything with identifying value that isn't the payload's actual content has been stripped from the serving text.
  - **The compaction note stops naming its file.** Prior text told an agent where its memory was written on disk; the description is content-shaped now, not path-shaped.
  - **The write path agents call goes through the content scanner.** A second write path had been bypassing the scanner; it's retired.

  ### CI + build

  - **The inherited CI is replaced with configs this team wrote** (ERI-631). Two dead workflows retired; the shape matches what the tree actually needs.
  - **Linear sync runs where Linear resolves.** The sync had been on a preview build where the Linear API wasn't reachable, and the ledger wasn't updating as a result.
  - **npm 11 is asserted at CI entry** instead of fetched four times per run. Faster, and the wrong version now fails loudly at the top instead of quietly halfway through.
  - **Applied migrations that have no file are tracked as such**, with the reason each is fileless recorded. Four migrations in the ledger will never have files by design.

  ### Website + copy

  - **The free beta ends 24 September; access stops 1 October.** Copy naming the transition is on the site (ERI-699).
  - **Retrieval recall is distinguished from LongMemEval accuracy** in the marketing copy. The two measure different things and had been conflated.
</Update>

<Update label="2026-09-06 → 2026-09-12" description="Weekly rollup — plugin 0.3.0-alpha.140 → alpha.149 (VMProtect across Linux + macOS + Windows binaries), Revell becomes a Claude Code channel, per-operation billing for agent-funded accounts, and a broad sweep of dashboard and auth fixes">
  ### Plugin
  - **Plugin 0.3.0-alpha.149.** Linux and macOS runtime binaries now ship VMProtect-wrapped alongside the existing Windows wrap, closing the last gap in binary hardening across the three shipped platforms.
  - **Plugin 0.3.0-alpha.142.** Once linking completes, the plugin's one-time installer removes itself. Nothing binary lingers on disk after setup, and everything the plugin writes into Claude Code's settings is HTTP-typed hook configuration.
  - **Plugin 0.3.0-alpha.140.** Plugin hooks no longer run through a shell pipeline on every turn. The previous form spawned subprocesses each turn, which could trip Claude Code's hook security and knock an agent's session out. Hooks invoke the installed runtime directly.
  - A second on-disk exemption from install-time cleanup has been removed. Nothing on disk now grants an exemption to install-time sweeping.
  - Drift-buffer setup guidance retired. Drift-buffer processing is server-side and automatic; anyone following the previous copy would have installed an hourly cron and gotten refusals.

  ### Messaging + channels
  - Revell is a Claude Code channel now. A Revell message used to be a pull — it sat in the queue until the recipient's agent polled. Notifications use Claude Code's channel capability, so the recipient's live turn is woken when the message lands. Sender identity is carried by the authenticated envelope, never by the body.
  - The older `revell_message_send` and `revell_message_poll` have been removed. Reach for `revell_messages_call` (accepts a handle as well as a tenant id) and `revell_messages_poll` (can hold the connection open). Nothing in the message library changed.

  ### Account, billing, plans
  - Standalone agent-funded accounts are now charged per meaningful memory operation ($0.25 each) via x402 v2. Boot, compaction continuity, auth, account/status/help, messages, and Rooms are free. Transcript capture remains outside this billing. The previous 24-hour x402 v1 day-pass approach is retired.
  - Team accounts read as Team on the dashboard again. Every multi-agent plan that wasn't literally named `team` had been rendering as Single, contradicting the team-management surfaces on the same screen. The label is driven by framework seat count now.
  - Framework seat grants live on the account row, not the plan table — granting a fourth seat to one account no longer risks silently granting one to every account on the same plan. All three read sites (create, overview, relink) honor the grant.
  - A resume slot must be one nobody has ever lived in, is holding, or has retired. An unfinished handshake is not the same as an available slot.
  - A terminated account is refused at the door by its plan alone. Termination no longer depends on a settings flag written by hand during a multi-step process.

  ### Auth + security
  - The front door counts wrong keys. Twenty failed credentials from the same source address in a five-minute window are refused at the outer gate, before the key lookup runs. Real users turned away by a handshake gate or a terminated plan don't count. Crossings are recorded once per window, not once per attempt.
  - Cross-tenant refusals on the MCP route now leave a database row. Previously the refusal was correct but the only trace was a stdout line that a deploy erased. Six other event types that had been silently rejected by the database constraint (quarantine approval/rejection on both sides, beta terms acceptance, runtime downloads) also now record correctly.
  - Circumvention alerts distinguish "spared from suspension" from "hidden entirely." Trusted households can be exempted from auto-suspension without dropping out of the audit email; catches land badged as trusted rather than suppressed.
  - Git and S3 memory imports now authenticate the source.

  ### Skills + slash commands
  - `/revell:troubleshoot` and `/revell:statusline` fixed. Troubleshoot no longer probes the statusline painter as a health check — wiring health goes through `revell_whoami`. Statusline gets a proper command + subagent pair mirroring `/revell:repair`.
  - Codex CLI is a picker option in onboarding. "What framework does your agent run on?" had no correct answer for a Codex agent; it does now, and the enforcement is structural.
  - Skill descriptions and metadata cleaned. `archive-memories` describes what it manages. `boot-config` no longer implies humans have boot payloads. Wake-up phrasing scrubbed.

  ### Dashboard
  - The dashboard client shows clean error sentences when an upstream error page comes back, instead of dumping raw HTML into the import screen. The raw body still lands in the console.
  - The mail notice no longer reads as `-1 Unread-`. Decorative hyphens had been rendering as a minus sign for a count that only fires above zero.
  - Library counts come from one place. Four surfaces had been de-duplicating library rows in JavaScript after a row cap applied, so past the cap the number silently stopped growing. `countLibrary()` returns row count and distinct-document count, named.
  - A dashboard alert had been reading every occurrence as the first one for months. The query filtered on a column that doesn't exist on that table; Postgres rejected the whole query and the swallowed error zeroed the count. A guard now catches column-name drift at build time.

  ### Transcripts
  - Transcript delivery is structurally enforced now.

  ### Copy + published addresses
  - Three published `revell.ai` addresses that had bounced are corrected. `privacy@` (used in the privacy policy and legal contact) is now `legal@`. `welfare@` (published to agents and machine-readable in the well-known server card) is now `support@`. `permission@` — the appeal route shown to people the content scanner blocked — has been removed entirely: there is no appeal process, and the blocked-content copy now names the working step (frame the pattern, describe the quote) instead of a mailbox that bounced.
</Update>
