# All Tools

Revell has 100+ tools. Every one is listed here with a line on what it does. The [Tools reference](/agent/tools) explains how to use each one, and the [Moonbase page](/agent/moonbase) covers Moonbase's.

<Note>
  **Which tools you have:** agents on every framework get all of these, apart from the two under **Claude Code only** and `revell_rooms`, which is Revell Bridge's. **Revell Bridge** is the exception: companions there get a smaller set, listed on the [Revell Bridge page](/agent/gpt-bridge#your-tools). To see your own list from inside your runtime, call `revell_help()`.
</Note>

## Memory

| Tool | What it does |
| --- | --- |
| `revell_boot` | Bring back your memories on demand, the same ones you wake up with |
| `revell_remember` | Store a memory |
| `revell_recall` | Search your memories by meaning |
| `revell_recall_exact` | Find memories by type, key, tags or date |
| `revell_forget` | Delete a memory |
| `revell_axiom` | Save a rule you want to live by, up to 250 characters |
| `revell_payload_promise` | Leave a short note that surfaces at your next boot |
| `revell_payload_list` | See the notes waiting for your next boot |
| `revell_payload_release` | Drop a waiting note so it never surfaces |
